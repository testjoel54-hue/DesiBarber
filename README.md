# Desi Barber Premium Website

## Run locally
npm run dev

## Web3Forms
Open `site/assets/booking.js` and replace:
`YOUR_WEB3FORMS_ACCESS_KEY`
with your Web3Forms form access key.

## Deploy to Vercel
- Framework: Other
- Build command: `npm run build`
- Output directory: `dist`

## Booking behavior
This site sends appointment requests through Web3Forms. It does not reserve live availability or prevent double-booking. The shop must confirm each requested appointment.
